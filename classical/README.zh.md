# Nayin v2 · 六十甲子纳音：原典关系表

`bazi-nayin` v1 给了三十纳音的名字和英译。v2 加上**怎么读**：每一柱在原典里是什么象、处在气的哪一段、喜什么、忌什么、哪一行克不动它。所有关系都附原文，可逐字核对。

**来源**：《三命通會》卷一（明·萬民英），四庫全書本，維基文庫錄文。原文屬公有領域，副本在 `source/`。

## 三层，全部出自卷一

| 层 | 原典章节 | 字段 |
|---|---|---|
| 气的六段 | 〈論納音取象〉：「甲子納音象，聖人喩之，亦如人一世之事也」 | `arc`：按地支对分六段，子丑「始孕」→ 戌亥「閉塞歸根」 |
| 逐柱象与喜 | 〈釋六十甲子性質吉凶〉小注 | `image`、`likes`（神煞与字形标签已剥去，原注留在 `note_raw`） |
| 逐柱喜忌 | 同章下文逐段 | `relations`：`state` / `welcome` / `avoid` / `unharmed_by` + `quotes` |
| 大小之变 | 同章「右件六十甲子……」 | `scale`：`large` / `small`，规则原文在 `scale_rule_quote` |

## 纳音 × 纳音矩阵（`nayin-matrix.json` / `.csv`）

卷一另有三十章纳音专论，每章写这一个纳音逢其他纳音时如何。矩阵按章逐条整理，**行是主体，列是它遇到的那一个**：

| 符号 | 含义 | 原文用语举例 |
|---|---|---|
| `+` | 喜 | 喜見、最吉、主貴、相資 |
| `-` | 忌 | 忌、不宜、最凶、主夭 |
| `~` | 有条件 | 「有水濟亦可」「無木則凶」，或原文只限某一柱（「乙丑獨吉」） |
| `0` | 无用 | 無用、無益、無干涉 |

CSV 中带 `*` 的格子不是原文点名，而是由「餘金無用」「見木皆吉」这类泛指推及的。空格表示原文没提。

**关系是有方向的。** 同一对纳音，两章常常看法相反，共 41 对。比如劒鋒金章说见楊柳木吉（能斫），楊柳木章却说忌劒鋒（被斫）。要问「谁得益」，读主体那一行。

## 怎么用

- `welcome` / `avoid` 里两字的是干支（原文点名），单字的是五行（原文泛指）。
- `unharmed_by` 表示通常克它的那一行，原典说在这一柱上失效，例如 丙午丁未（天河水）「土不能克」。机制在原文里都写了，大多是那一行到了这个地支正处于死、绝、墓位（「木至子無氣」）。
- 同卷有两说相反的，照录两说，写在 `textual_notes`；疑似讹字也记在这里（辛巳条的「丙辰」）。

## 立场

这是一张**原典记了什么**的表，不代表这些关系会应验。「喜」「忌」是原典用语，我们照录，不替它下判断。纳音属古法一脉，与子平法的干支五行是两套体系，本表不参与旺衰计算。

## 重建

```
python3 extract.py   # 切段、定位，生成 nayin-v2.raw.json
python3 build.py     # 合并 curated.py 的人工整理，逐条核对引文，输出 nayin-v2.json / .csv
python3 build_matrix.py  # 合并 curated_matrix.py，按章核对引文，输出 30×30 矩阵
```

`build.py` 会检查三件事：每句引文都能在原文里逐字找到（已统一异体：尅→克、干位上的巳/已→己）；点名的干支都出现在所附引文中；六十柱无一遗漏。
